## Ortho English Coach

整形外科の国際学会で質疑応答を乗り切るための英語と、パブ・コメディ・ラップまで届く日常英語を、
同じアプリの2モードで練習します。

### モード

- **🎓 学会フォーマル** — 13セクション / 約150フレーズ
  聞き取れないときの逃げ方、時間の稼ぎ方、限界の認め方、丁寧な反論、統計・方法論、手術と臨床の説明、
  PRP・再生医療の質疑、質問する側、座長として、発音の落とし穴、休憩時間の社交。
- **🎤 ストリート／日常** — 10セクション / 約150フレーズ
  2002→2026のスラング棚卸し（死語と新語）、UKパブ語彙、英国式ホンネ翻訳、US日常、皮肉とコメディの型、
  ラップ／ヒップホップ語彙、AAVEの文法と作法、ネット発の語、学会後のパブ、TPOと地雷ワード。

### 🎙 Gemini Live 用スクリプト（肩関節外科）

音声AI（Gemini Live など）に貼り付けて、声で質疑応答を回すための台本を10本収録。
コピーボタン一つで持ち出せます。

- **学会の質疑応答** — ARCR（鏡視下腱板修復術）／RSA（リバース型人工肩関節）／拘縮肩・凍結肩／
  オーバーヘッドアスリート／汎用テンプレ。それぞれ実際に飛んでくる批判の角度を7〜9個仕込んであり、
  1問ごとに日本語でフィードバックが返る設定。
- **聞き取り・発音の特訓** — 訛り（インド・スコットランド・米南部・独伊）＋早口＋長い前置きを再現した
  聞き取り地獄モード／肩の用語29語の発音チェック。
- **役割を変えて練習** — 座長つきフルセッション（時間超過を注意される練習込み）／自分が質問する側／
  学会後のパブ。

### 機能

- **読み上げ** — en-GB / en-US / en-AU を切り替え。通常速度と 0.68倍のゆっくり再生。
- **発話判定** — 「🎙 話す」で自分の声を認識し、目標文との一致率と単語ごとの過不足を表示。
- **質疑応答シミュレーター** — 想定質問がランダムに音声で飛んでくる。タイマーで反応速度を測り、
  模範解答とキーフレーズを確認して自己採点。
- **シャドーイング・ドリル** — 定着度（Lv0〜5）の低いフレーズを優先して出題。
- **ダイアログ** — 学会・パブの多ターン会話を通しで再生。
- **記録** — 今日の練習数、連続日数、定着数、★お気に入り、日本語を隠すモード。

### 動作環境

- iPhone / iPad は **Safari**、PC は **Chrome** を推奨。
- 発話判定は Web Speech API を使うため、Chrome / Safari 以外では使えない場合があります
  （読み上げとフレーズ閲覧はどのブラウザでも動きます）。
- 初回の「🎙 話す」でマイクの許可を求められます。
- ホーム画面に追加するとアプリのように全画面で使えます。
