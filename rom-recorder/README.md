# ROMレコーダー — 関節角度計測・記録アプリ

整形外科診察・リハビリでの関節可動域(ROM)計測と、その記録を補助する**完全無料**の静的Webアプリです。
サーバ不要・アカウント不要で、映像・画像・記録はすべて**端末内でのみ**処理されます(外部送信なし)。

> 本アプリは計測記録を補助する研究・教育用ツールであり、**医療機器ではありません**(薬機法上の承認・認証なし)。
> 診断・治療方針の決定は標準的な計測(ゴニオメーター等)と医師の判断で行ってください。

## できること

| タブ | 機能 |
|---|---|
| **AIカメラ** | カメラ映像から MediaPipe Pose(同梱)でリアルタイム角度計測。プリセット: 肩屈曲/外転・肘屈曲・股屈曲/外転・膝屈曲・足背屈/底屈(左右)。計測中の最大・最小を追跡し1タップで記録 |
| **動画解析** | 動画ファイルを解析して角度の時系列グラフ・最大/最小を表示。時系列CSV出力。グラフタップで動画シーク(歩行・立ち上がり等の動作解析) |
| **写真計測** | 写真・X線画像上でデジタルゴニオメーター。3点角モードと2直線モード(Cobb角・FTAなど)。ピンチズーム・回転・点のドラッグ微調整(拡大鏡付き) |
| **記録** | 患者ID(匿名化推奨)ごとに保存。フィルタ・経過グラフ(参考可動域の点線表示)・CSVエクスポート・JSONバックアップ/復元 |
| **設定** | 参考可動域の入力(既定は空欄・要確認候補の一括入力ボタン付き)、AIモデル選択、免責表示 |

PWA対応: ホーム画面に追加するとアプリのように使え、初回読み込み後はオフラインでも動作します。

## 起動方法(すべて無料)

### A. ローカルで使う(完全オフライン)
このフォルダ(`rom-recorder/`)で:

- **Windows**: `start-app.bat` をダブルクリック
- **Mac/Linux**: `python3 serve.py`

→ ブラウザで http://localhost:8000 が開きます。

> `index.html` を直接ダブルクリック(file://)して開いた場合、ブラウザの仕様により**カメラ機能だけは動きません**(写真計測・記録は動きます)。上記のローカルサーバ経由か、下のHTTPS公開でご利用ください。

### B. GitHub Pages で公開(iPad・スマホから使う)
1. リポジトリを **Public** にする(Privateのままの場合は有料プランが必要)
2. GitHub の Settings → Pages → 「Deploy from a branch」→ Branch: `main` / `/ (root)` を選択
3. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/rom-recorder/` でアクセス

HTTPSなので、iPad・スマホのカメラもそのまま使えます。

### C. その他
Netlify / Cloudflare Pages などの無料ホスティングに `rom-recorder` フォルダを置いても動きます。

## 撮影のコツ(精度に直結)

- **計測面に対して直角にカメラを置く**: 屈曲・伸展系は真横(矢状面)から、外転系は正面(前額面)から。斜めからの撮影は角度が系統的に歪みます(2D計測の原理的限界)
- 対象関節を含む範囲(できれば全身)を映し、対象肢が体幹や服で隠れないようにする
- 各プリセットの画面上部に撮影方向のガイドが表示されます
- 3点角の性質上、**過伸展(0°未満)は屈曲との区別ができません**

## 精度と限界(文献)

マーカーレス姿勢推定によるROM計測の妥当性は「課題依存」です(すべてPubMed収載):

- 片脚着地の膝外反角: 光学式との絶対誤差 約19°、変化量としては良好 — [PMID 39281584](https://pubmed.ncbi.nlm.nih.gov/39281584/)
- 高齢者歩行: 大きな運動は光学式に匹敵、足関節など小さい運動は誤差が出やすい — [PMID 37744429](https://pubmed.ncbi.nlm.nih.gov/37744429/)
- 体幹・肩の姿勢評価では条件により RGB-D センサの代替になり得る — [PMID 41755089](https://pubmed.ncbi.nlm.nih.gov/41755089/)
- 肘・膝・股ROMで ICC 0.005–0.68 と報告し、臨床導入は時期尚早とする報告 — [PMID 42215670](https://pubmed.ncbi.nlm.nih.gov/42215670/)

→ 本アプリのAI計測は**スクリーニングと経過記録の補助**という位置づけです。確定値が必要な場面ではゴニオメーター・X線計測(写真計測タブの手動計測を含む)をご利用ください。

## 参考可動域(基準値)について

真正性確保のため**既定値は空欄**です。設定タブの「一般的な候補値をまとめて入力」ボタンで一括入力できますが、この候補値は二次情報由来で、日本整形外科学会・日本リハビリテーション医学会「関節可動域表示ならびに測定法」(2022年4月改訂)の**原典PDFとは未照合(要確認)**です(本アプリ作成時、原典が機械取得できなかったため)。設定タブ内の原典リンクからご確認のうえ、必要に応じて修正してください。照合状況の詳細は [docs/software-survey.md](docs/software-survey.md) に記載しています。

## データとプライバシー

- 記録はブラウザの localStorage に保存。映像・画像はメモリ内処理のみで、**外部への送信は一切ありません**(AI推定も端末内のWASM/GPUで実行)
- ブラウザの「サイトデータ削除」で記録が消えることがあります。記録タブから**定期的にJSONバックアップ**を保存してください
- 患者IDには氏名・カルテ番号そのものではなく、**匿名化した研究ID等**を使用してください

## 技術構成・開発

- 素のHTML/CSS/JS(ビルド不要・依存ライブラリなし)。グラフもcanvas自前描画
- 姿勢推定: [@mediapipe/tasks-vision 1.0.1](https://www.npmjs.com/package/@mediapipe/tasks-vision)(Apache-2.0)を `vendor/` に同梱(オフライン動作・バージョン固定のため。詳細は [vendor/README.md](vendor/README.md))
- モデル: `pose_landmarker_lite`(同梱)。高精度版 `full` は設定から選択(初回のみCDN取得)
- テスト:
  - ユニット: `node tests/angle-core.test.js`(角度計算・CSV・保存/復元の20件)
  - 実機: Playwright(フェイクカメラ)でタブ動作・写真計測90°・記録/CSV・AI初期化を検証し、公式サンプル人物画像で検出33点と角度の妥当性(肘伸展・肩外転90°台・片膝屈曲)を確認済み
- 更新時は `sw.js` の `VERSION` を上げるとオフラインキャッシュが入れ替わります

```
├─ sw.js / manifest.webmanifest / icons/  PWA

```
