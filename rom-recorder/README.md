# ROMレコーダー — 関節角度計測・記録アプリ

整形外科診察・リハビリでの関節可動域(ROM)計測と、その記録を補助する**完全無料**の静的Webアプリです。
サーバ不要・アカウント不要で、映像・画像・記録はすべて**端末内でのみ**処理されます(外部送信なし)。

> 本アプリは計測記録を補助する研究・教育用ツールであり、**医療機器ではありません**(薬機法上の承認・認証なし)。
> 診断・治療方針の決定は標準的な計測(ゴニオメーター等)と医師の判断で行ってください。

## できること

| タブ | 機能 |
|---|---|
| **AIカメラ** | カメラ映像から MediaPipe Pose(同梱)でリアルタイム角度計測。プリセット: 肩屈曲/外転・肘屈曲・股屈曲/外転・膝屈曲・足背屈/底屈(左右)。計測中の最大・最小を追跡し1タップで記録 |
| **動画解析** | 動画ファイルを解析して角度の時系列グラフ・最大/最小を表示。時系列CSV出力。グラフタップで動画シーク(歩行・立ち上がり等の動作解析) |
| **写真計測** | 写真・X線画像上でデジタルゴニオメーター。3点角モードと2直線モード(Cobb角・FTAなど)。ピンチズーム・回転・点のドラッグ微調整(拡大鏡付き) |
| **MMT** | 脊椎疾患の徒手筋力テストをその場で入力。頸髄C5〜T1・腰仙髄L2〜S1のkey muscle(ISNCSCI)を左右一覧で、タップまたは**音声**で記録。言い直しは上書きされ重複しません |
| **記録** | 患者ID(匿名化推奨)ごとに保存。フィルタ・経過グラフ(参考可動域の点線表示)・CSVエクスポート・JSONバックアップ/復元。角度も**音声**で記録できます |
| **設定** | 参考可動域の入力(既定は空欄・要確認候補の一括入力ボタン付き)、AIモデル選択、ISNCSCI準拠モード、音声入力の有効化、免責表示 |

PWA対応: ホーム画面に追加するとアプリのように使え、初回読み込み後はオフラインでも動作します。

## 起動方法(すべて無料)

### A. ローカルで使う(完全オフライン)
このフォルダ(`rom-recorder/`)で:

- **Windows**: `start-app.bat` をダブルクリック
- **Mac/Linux**: `python3 serve.py`

→ ブラウザで http://localhost:8000 が開きます。

> `index.html` を直接ダブルクリック(file://)して開いた場合、ブラウザの仕様により**カメラ機能だけは動きません**(写真計測・記録は動きます)。上記のローカルサーバ経由か、下のHTTPS公開でご利用ください。

### B. GitHub Pages で公開(iPad・スマホから使う)
1. リポジトリを **Public** にする(Privateのままの場合は有料プランが必要)
2. GitHub の Settings → Pages → 「Deploy from a branch」→ Branch: `main` / `/ (root)` を選択
3. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/rom-recorder/` でアクセス

HTTPSなので、iPad・スマホのカメラもそのまま使えます。

### C. その他
Netlify / Cloudflare Pages などの無料ホスティングに `rom-recorder` フォルダを置いても動きます。

## 音声入力の使い方と注意

診察の手を止めずに記録するための機能です。患者の切替から値の入力まで音声だけで進められます。

| 場面 | 言い方の例 |
|---|---|
| 患者切替 | 「**患者 A12**」／「かんじゃ エー012」／「患者ID 0034」 |
| MMT | 「**右 L4 4**」／「左 前脛骨筋 3プラス」／「みぎ エル4 5」 |
| 角度 | 「**膝 屈曲 右 120**」／「右膝屈曲120度」／「肩外転 左 九十」 |

### 氏名が記録されない仕組み(構造的な歯止め)

患者の指定は、次の**二重の条件を満たしたときだけ**採用されます。

1. 「患者」「かんじゃ」等の**合図語**がある発話であること
2. その後ろが**ID形式(英字0〜3文字＋数字1〜6桁)**であること

日本語の氏名はこの形式に合致しないため、**うっかり口にしても患者IDとして登録されません**(画面には「採用できません」と表示されます)。既存の患者IDを言った場合は、ハイフン等の表記ゆれを吸収して既存IDに解決します(例:「患者 A012」→ `A-012`)。

- 角度計を見ながら判断した値をそのまま口頭で入れられます。角度は記録ダイアログに反映され、**1タップで保存**(患者IDの取り違えを防ぐため確認を挟みます)
- MMTは発話ごとに**即保存**。同じ部位を言い直すと上書きされ、重複しません
- 左右が聞き取れなかった発話は**保存しません**(左右の取り違えは重大なため)。「膝屈曲 999」のようなありえない値も棄却します
- 音声で入れた記録には**認識テキストがメモとして残り**、後から検証できます

> ### ⚠️ プライバシー上の重要な注意
> 音声認識はブラウザ標準機能(Web Speech API)を使います。**Chrome/Edge系では既定で音声データが認識サーバーへ送信されて処理されます**(MDN公式に明記: [Using the Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API/Using_the_Web_Speech_API))。Safariの処理がローカルかサーバーかは公式情報で確認できませんでした(**未確認**)。
>
> 本アプリの対策:
> - 音声入力は**既定オフ**。初回に注意事項へ同意したときだけ有効になります
> - 端末内処理が使える環境では**自動的にそちらを優先**します(`processLocally`。対応ブラウザ・対応言語のみ)。実際にどちらで動いているかは画面に「🔒 端末内」「☁️ サーバー」と表示されます
> - 音声で扱えるのは**部位・左右・数値**と**ID形式の患者ID**のみ。**氏名は形式が合わないため登録されません**
> - ただし匿名化IDであっても、サーバー処理時には認識サーバーへ送られます。厳格な運用が必要な場合は端末内処理が使える環境をご利用ください
> - この機能はオフラインでは動作しません(他の機能はオフラインで使えます)

対応ブラウザ: Chrome / Edge / Safari(14.1・iOS 14.5以降、Siri有効化が必要)。**Firefoxは非対応**です。

## MMT(徒手筋力テスト)について

- 髄節ごとの筋・テスト動作は **ISNCSCI(ASIA/ISCoS国際標準)のkey muscle function** に準拠しています(C5肘屈筋〜T1小指外転筋、L2股屈筋〜S1足関節底屈筋)。出典は設定タブに掲載
- グレード定義もISNCSCIの運動スコア定義(0〜5)に基づきます
- **「4+」「3−」などの中間表記について**: これはMRC/ISNCSCI標準の一部ではなく臨床上の慣用で、ISNCSCIは「0〜5の整数で採点しプラス・マイナスは付けない」と規定しています。また中間表記を足しても評価者間一致は改善しないとの報告があります([PMID 29051814](https://pubmed.ncbi.nlm.nih.gov/29051814/): 一致率 標準64%→修正48%、Fleiss κ 0.02/0.13でいずれも不良)。
  そのため本アプリでは、通常は±を使えるようにしつつ、設定の**「ISNCSCI準拠モード」**を有効にすると±が無効化され、UEMS/LEMS(各50点満点)の合計が表示されます
- テスト肢位の詳細パラメータやASIA公式PDFの逐語表現は、本アプリ作成時に機械照合できていません(**未確認**)。運用前に原典でご確認ください

## 撮影のコツ(精度に直結)

- **計測面に対して直角にカメラを置く**: 屈曲・伸展系は真横(矢状面)から、外転系は正面(前額面)から。斜めからの撮影は角度が系統的に歪みます(2D計測の原理的限界)
- 対象関節を含む範囲(できれば全身)を映し、対象肢が体幹や服で隠れないようにする
- 各プリセットの画面上部に撮影方向のガイドが表示されます
- 3点角の性質上、**過伸展(0°未満)は屈曲との区別ができません**

## 精度と限界(文献)

マーカーレス姿勢推定によるROM計測の妥当性は「課題依存」です(すべてPubMed収載):

- 片脚着地の膝外反角: 光学式との絶対誤差 約19°、変化量としては良好 — [PMID 39281584](https://pubmed.ncbi.nlm.nih.gov/39281584/)
- 高齢者歩行: 大きな運動は光学式に匹敵、足関節など小さい運動は誤差が出やすい — [PMID 37744429](https://pubmed.ncbi.nlm.nih.gov/37744429/)
- 体幹・肩の姿勢評価では条件により RGB-D センサの代替になり得る — [PMID 41755089](https://pubmed.ncbi.nlm.nih.gov/41755089/)
- 肘・膝・股ROMで ICC 0.005–0.68 と報告し、臨床導入は時期尚早とする報告 — [PMID 42215670](https://pubmed.ncbi.nlm.nih.gov/42215670/)

→ 本アプリのAI計測は**スクリーニングと経過記録の補助**という位置づけです。確定値が必要な場面ではゴニオメーター・X線計測(写真計測タブの手動計測を含む)をご利用ください。

## 参考可動域(基準値)について

真正性確保のため**既定値は空欄**です。設定タブの「一般的な候補値をまとめて入力」ボタンで一括入力できますが、この候補値は二次情報由来で、日本整形外科学会・日本リハビリテーション医学会「関節可動域表示ならびに測定法」(2022年4月改訂)の**原典PDFとは未照合(要確認)**です(本アプリ作成時、原典が機械取得できなかったため)。設定タブ内の原典リンクからご確認のうえ、必要に応じて修正してください。照合状況の詳細は [docs/software-survey.md](docs/software-survey.md) に記載しています。

## データとプライバシー

- 記録はブラウザの localStorage に保存。映像・画像はメモリ内処理のみで、**外部への送信は一切ありません**(AI推定も端末内のWASM/GPUで実行)
- ブラウザの「サイトデータ削除」で記録が消えることがあります。記録タブから**定期的にJSONバックアップ**を保存してください
- 患者IDには氏名・カルテ番号そのものではなく、**匿名化した研究ID等**を使用してください

## 技術構成・開発

- 素のHTML/CSS/JS(ビルド不要・依存ライブラリなし)。グラフもcanvas自前描画
- 姿勢推定: [@mediapipe/tasks-vision 1.0.1](https://www.npmjs.com/package/@mediapipe/tasks-vision)(Apache-2.0)を `vendor/` に同梱(オフライン動作・バージョン固定のため。詳細は [vendor/README.md](vendor/README.md))
- モデル: `pose_landmarker_lite`(同梱)。高精度版 `full` は設定から選択(初回のみCDN取得)
- 音声入力: ブラウザ標準の Web Speech API。認識テキストの解釈は依存なしの自作パーサー(`js/voice-parse.js`)で、漢数字・全角・かな読み・「L4のLを左と誤認しない」等を単体テスト済み
- テスト:
  - ユニット: `node tests/angle-core.test.js`(角度計算・CSV・MMT保存/復元の31件)、`node tests/voice-parse.test.js`(音声解釈の34件。氏名が患者IDとして採用されないことを含む)
  - 実機: Playwright(フェイクカメラ)でタブ動作・写真計測90°・記録/CSV・AI初期化を検証し、公式サンプル人物画像で検出33点と角度の妥当性(肘伸展・肩外転90°台・片膝屈曲)を確認済み。音声は認識APIをモックして、MMT入力・言い直しの上書き・左右不明の棄却・患者IDの音声切替・**氏名がどの記録にも残らないこと**・監査用テキスト保持・角度ダイアログ反映を検証済み
- 更新時は `sw.js` の `VERSION` を上げるとオフラインキャッシュが入れ替わります
