BRIDGE DX ／ ONE-PC LOCAL SETUP

つなぎDXの方向性 ― ローカル1台で、Gemini/Claude を安全に使う

電子カルテ導入までの「つなぎ」として、院内PC1台をハブに、Gemini/Claude APIを組み合わせて安全に運用する。津軽弁の議事録にも対応できる、シンプルで拡張可能な構成。

CONTEXT

まず現状の整理

試したAI議事録（取れる君）もWhisperも津軽弁で崩壊し、実用に届かなかった。市販の「議事録SaaS」や従来型STTは標準日本語モデル前提で、方言に構造的に弱い。
検証の結論：同一のNHK録音での3エンジン比較でGeminiが圧勝（方言のまま文字起こし＋標準語訳、固有名詞も正確）。よって議事録はGemini直接音声入力を本命とし、ローカルPC1台をハブに匿名化・整形・保存を組み合わせる。
今回の方針＝「電子カルテ導入までのつなぎ」。大がかりな契約や全院展開は避け、院内PC1台＋Gemini/Claude API＋少数スタッフで回す。うまく回ったら横に広げる。

DIALECT

津軽弁への現実的な対応「文字起こしを直す」のではなく「起こす対象を変える」

検証済み（2026年5月・同一のNHK録音・マイク手持ち収録で3エンジン比較）：Geminiの圧勝。
▸ アナウンサー部分（クリーンな標準語）：取れる君=ほぼ正確／Whisper=誤りあり（「馬に襲われて」「千木市」等）／Gemini=ほぼ完璧（固有名詞・数値まで正確）。
▸ 津軽弁インタビュー：取れる君=崩壊／Whisper=崩壊＋幻覚／Geminiのみ方言のまま文字起こし＋標準語訳併記（「まんず、あど、仲良ぐしでけで」→「まず、あとは、仲良くしてくれて」）。
→ 議事録の本命エンジンは Gemini 直接音声入力に確定。
検証から言えること（重要）：①マイク手持ち＝録音品質良好でもこの結果＝失敗の主因は録音環境ではなくエンジン。②取れる君はアナウンサーの標準語なら正確→院内会議で「標準語を意識」しても崩壊したのは、意識では消えない津軽訛りが残るため。③Whisperはクリーンな標準語ですら誤る→ローカルWhisperによるディクテーション案は期待薄。従来型STTを追い込む方向に時間を使わない。

運用の3つの型（本命A＋保険B/C）

A

Gemini直接音声（本命）

カンファ録音をそのままGeminiへ。「方言のまま文字起こし＋標準語訳＋議事録体裁に整形」まで1プロンプトで指示。医師は[?]箇所と要点を5〜10分確認。検証済みで精度は実用圏。

B

ディクテーション（Gemini＋仮名）

紹介状・サマリの下書きは患者名を「患者A」等と吹き込んでGeminiへ。返った下書きの仮名を院内で実名に置換。※Whisperはアナウンサー音声でも誤ったためローカル処理案は期待薄（試すなら5分テストのみ）。

C

メモ→整形（保険）

騒がしい会議・録音不可の場面は走り書きメモをLLMで議事録体裁に整形。音声認識を迂回する保険として維持。

A型の注意（重要）：音声を外部に送る＝「生音声は院外に出さない」原則の例外になる。運用条件を先に固める： ①会議録音は患者氏名を発話しないルール（「303号室の方」等で呼ぶ）で録る／②送信は法人契約（Vertex AI等・学習利用オフ・保存最小）経由のみ／③検証はNHK録音＝クリア音源。実カンファは複数話者・雑音で条件が悪いため、マイクを話者に近づける・決定事項は座長が復唱する等の録音品質対策を併用する。

SECURITY

安全に運用する7つの原則

11台に集約・施錠部屋

診療エリア外の施錠部屋に設置。盗難防止ワイヤー。使う人は数名に限定。

2ディスク暗号化＋生体認証

FileVault / BitLocker を有効化。Touch IDまたはPINで解除。自動ロック3分。

3ネットワーク分離

院内Wi-Fi（業務用SSID）に接続。他PCとのファイル共有はオフ。院外VPNは使わない。

4API通信の最小化

APIキーはKeychain/秘密環境変数で管理。患者情報はマスクしてから送信。学習利用オフを法人契約で担保。

5監査ログを残す

「いつ・誰が・何をAPIに送った」をJSONで自動記録。週1回、医師が目視レビュー。

6USB・外部通信の制限

USBストレージは基本禁止。バックアップ用の暗号化SSD1本のみ許可。クラウド同期は入れない。

7週次バックアップ・世代管理

暗号化外付けSSDに週次で差分バックアップ。4世代残す。SSDは施錠保管。

8撤収手順を先に決める

電カル導入時にPCを廃棄する手順（データ完全消去・SSD物理破壊）を今から明文化しておく。

USE CASES

この1台で何をするか

1. カンファ議事録

録音（患者名は発話しない）→ Gemini直接音声で「方言まま＋標準語訳＋議事録整形」→ 医師5〜10分確認。清書ゼロ。

2. 紹介状・退院サマリ 下書き

患者名を「患者A」で吹き込み（Gemini）or 要点打ち込み → LLMが下書き → 実名置換・加筆修正。

3. 文献・ガイドライン要約

PDFを投入 → 要点抽出。忙しい合間にキャッチアップ。

4. kintoneデータの分析補助

CSVを投げてトレンド抽出。院内会議の資料作りが速くなる。

5. 学会資料・図表の下書き

スライドの骨子作成、図表案の生成、英文校正。

6. 院内問合せ対応の下書き

問合せメール／稟議書のたたき台を数十秒で。
